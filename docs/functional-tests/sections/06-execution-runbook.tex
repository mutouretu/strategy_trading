\subsection{第一轮打通清单}

建议下一轮立即执行：

\begin{enumerate}[label=\arabic*.]
  \item Codex 创建独立功能测试数据库，自动跑 P1。
  \item Codex 先打通统一的 \texttt{.env} 加载，再启动 FastAPI，执行 P2 API 测试；此时不启动真实策略。
  \item Codex 复查币安测试币对无仓位无挂单，执行 P3。
  \item 用户授权后，Codex 执行 P4 的 10 USDT 多空闭环。
  \item Codex 创建一组最小限价网格；用户在币安页面完成 FT-CON-L01/L02/L03，Codex实时核对收敛。
  \item 一致性通过后再修改 Streamlit 数据层，进入 P6。
\end{enumerate}

\subsection{停止条件}

出现任一情况立即停止实盘阶段：

\begin{itemize}
  \item 测试币对出现无法解释的仓位或订单；
  \item 平仓单总量超过真实仓位且一个协调周期后仍未报警；
  \item 同一 Cell 产生两张有效建仓单或两张系统管理的有效平仓单；
  \item 清理脚本无法确认本次新增数量；
  \item 连续三轮持仓查询、撤单或补单失败；
  \item 发现 API Key、Secret 或完整签名参数进入日志/证据。
\end{itemize}

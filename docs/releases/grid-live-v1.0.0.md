# Grid Live v1.0.0

- 发布日期：2026-11-18
- 版本标签：`grid-live-v1.0.0`
- 实盘代码基线：`0111a363517072dac81295d20afc6a3bde1934ee`

这是固定区间等 U 网格的首个独立实盘版本号。标签指向发布时币安与 OKX 实盘进程使用的 `grid` 提交；先前的 `release/grid-live-2026-11-18` 日期标签也指向同一提交。版本号只覆盖网格实盘服务，不代表整个仓库的统一版本。

## 包含的能力

- 币安 U 本位永续与 OKX USDT 永续使用隔离的交易所连接和策略数据库，可在统一页面查看与操作。
- 固定价格边界、等比间隔、逐格等 U 预算；启动时为现价上方卖格预建仓位。近价滚动挂单窗口默认每侧 10 单，并按缺单、断档和价格优先级调整。
- 按单元格配对成交计算纯网格收益，扣除已确认的买卖手续费；部分成交、撤单、补单及重启后订单恢复由实盘引擎处理。
- 支持手动追加资金、策略级复投比例和逐格独立复投。复投在完整卖出周期后按手续费后的单元格净利累计，并受交易数量步长、可用余额及防重复记录约束。
- 固定网格原地重配保留策略 ID、历史累计收益、运行时间等策略级记录；新一代单元格的价格、预算、次数和复投记录从零开始。

## 发布核对

- 发布前核对币安和 OKX 实盘进程的工作目录均为 `strategy_trading_grid`，分支提交为 `0111a36`。打标签和提交发布说明没有重启或切换这些进程。
- 在该提交运行固定网格与重配相关回归测试：**49 项通过**。
- 标签保存代码快照，不包含本地 SQLite 策略数据库、API 凭证或运行中挂单状态。

## 本版边界

- 本版实盘固定等 U 网格以预建卖侧仓位的 `seeded` 模式运行；零预建仓的 `price_triggered` 模式及注册的网格 `TradingRule` 仿真抽象属于后续分支，不在本标签中。
- 本版没有现货固定网格。单元格纯网格收益和复投不分摊资金费；资金费由交易账户余额承担。
- 停止策略只暂停调度。撤销交易所挂单与处理已有仓位是独立操作。

实现和操作细节见 [`grid_trading/docs/fixed-equal-usdt-grid-plan.md`](../../grid_trading/docs/fixed-equal-usdt-grid-plan.md)、[`grid_trading/docs/fixed-grid-reconfiguration.md`](../../grid_trading/docs/fixed-grid-reconfiguration.md) 与 [`grid_trading/docs/grid-runtime.md`](../../grid_trading/docs/grid-runtime.md)。

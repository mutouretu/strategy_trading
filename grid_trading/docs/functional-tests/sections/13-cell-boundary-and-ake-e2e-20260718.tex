\section{2026-07-18 边界 Cell 与 AKE 双组页面 E2E}

\subsection{实现与安全边界}

详情页新增“上方新增、上方删除、下方新增、下方删除”四个边界操作。页面只向 FastAPI 写入动作队列，币安操作由共享调度器串行执行，避免 Web 请求与轮询同时修改同一 Cell。删除只接受请求时冻结的最上方或最下方 Cell；持仓、待平仓、人工检查、部分成交或撤单结果不确定时拒绝删除。待建仓 Cell 必须先获得币安零成交撤单结果，才允许删除。

Cell 增删完成后，SQLite 同一事务内重排 Cell 序号并同步策略 \texttt{grid\_count}，因此移动窗口不会在下一轮撤销人工调整。调度器对待处理动作抢占常规 50 秒轮询；进程若在撤单和动作收尾之间退出，重启后按冻结目标幂等完成数据库收尾。

\subsection{手动混入外部仓位的一致性实测}

项目负责人在 Binance Testnet 手动增加约 10 USDT 的 AKE LONG，用于验证同一 symbol、同一持仓方向下，网格逻辑仓位与外部仓位能否安全共存。测试只读观察多个 60 秒一致性周期，不执行撤单、补单或平仓。

平台实际 AKE LONG 为 100284，两个网格组的 Cell 逻辑仓位分别为 52600 和 42248，合计 94848；差额 5436 AKE 按标记价约 0.0018296 折合 9.94 USDT，与手动仓位一致。资源池持续记录 \texttt{actual=100284}、\texttt{logical=94848}、\texttt{unassigned=5436}、\texttt{shortage=0}，状态为 \texttt{unassigned}。这里的 \texttt{external\_reserved} 专指外部待平仓挂单占用的退出额度，因此本场景保持为 0 是正确语义；没有归属到 Cell 的手动真实仓位由 \texttt{unassigned} 表示。

旧组 5 个待平仓 Cell 的币安退出单覆盖量为 52600，新组 8 个待平仓 Cell 的退出单覆盖量为 42248，均严格等于各组 Cell 逻辑仓位，未因额外真实仓位而扩单。23 个预期活动订单全部存在，0 个预期单缺失、0 个未知活动单、0 个待处理 Cell 动作；观察窗口内只有正常的建仓、平仓及循环事件，没有资源重分配、人工复核、修复失败或不稳定事件。结论：\StatusPass。外部手动增加仓位不会被网格 Cell 认领，不改变现有 Cell、订单归属或退出覆盖；资源池能够明确暴露这部分未分配仓位供运维检查。

随后项目负责人手动平掉全部 5436 AKE 外部仓位。观察窗口内网格同时发生正常成交与闭环，净增加一格 5521 AKE：新组建仓单 \#212451810 成交后建立退出单 \#212459742；其余两笔 11158 和 5576 AKE 建仓均在随后完成对应闭环，净影响为 0。最终平台与 Cell 逻辑仓位均为 100369，资源池自动恢复 \texttt{unassigned=0}、\texttt{shortage=0}、\texttt{status=consistent}。两组所有预期活动订单存在且退出量与 Cell 一致，证明外部仓位退出与同期网格成交交错时仍能正确收敛。

在平台与 Cell 均为 134116 AKE 时，进一步由页面外手动平掉 1000 AKE，构造真实仓位小于逻辑仓位的部分短缺。测试前按 20:01:49 的标记价 0.00176882 预测新组 \#001 为最近 Cell；实际一致性处理发生在 12:03 UTC，该分钟标记价在 0.00175963--0.00176730 间波动并跨过两个候选 Cell 的距离分界，因此协调器按处理时快照选择旧组 \#006。原退出单 \#212470259 以零成交状态撤销，Cell 从 11381 缩为 10381，并在原卖出价 0.0017923 建立新退出单 \#212479434；状态继续为待平仓，循环次数不增加。最终实际与逻辑仓位均为 133116，资源池恢复 \texttt{consistent}，23 张预期活动订单全部存在，其他 Cell 无数量错配。

同一协调周期中，旧组远端 Cell 的退出单 \#212243433 独立变为 \texttt{EXPIRED}；系统保持其 10108 AKE 逻辑所有权，并自动恢复为 \#212479432，没有错误地将该异常与 1000 AKE 人工减仓合并处理。该结果同时验证了动态价格下跨组最近 Cell 选择、部分仓位穿透缩量，以及并发独立缺单修复的隔离性。

随后进一步手动平掉 20000 AKE，验证缺口跨越多个 Cell。协调器按处理时现价约 0.0018269 从跨组最近持仓开始吸收缺口：旧组 \#008 的 10940 AKE 与新组 \#004 的 5466 AKE 被完全释放，均清空仓位和退出单并复位为未触发；新组 \#005 吸收剩余 3594 AKE，从 5412 缩至 1818，并在原退出价 0.0018659 将退出单缩量重建为 \#212598924。三项减少量严格满足 $10940+5466+3594=20000$。由于处理时现价低于两格已释放 Cell 的买入价，它们在后续策略扫描中继续保持未触发，没有立即重新挂建仓单。

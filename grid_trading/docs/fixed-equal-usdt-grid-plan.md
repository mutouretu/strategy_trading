# 固定区间等 U 网格：币安测试网阶段

开发分支：`feat/fixed-equal-usdt-grid`。本阶段使用币安 U 本位永续测试网 `demo-fapi.binance.com`；OKX 与现货接入留在后续阶段。原有触发式移动网格保持独立策略类型。测试网交易使用专门的 `test.env`，不会把密钥提交到仓库。

## 策略口径

- 用户设定下界、上界、网格数 `N` 和交易预算 `B`。生成 `N+1` 个等比价格边界，逐格预算约为 `B/N`，最后一格吸收 8 位小数的预算尾差。币安数量按每格预算、对应买价和交易精度向下取整。
- 初始价格之上的 `S` 个卖格先按各自的 `格预算 / 格买价` 与交易所数量步长计算目标数量，再把数量合并开多一次。确认成交后，预先持久化的逐格数量分配给逻辑卖格；其余格子在各自买价挂买单。同一格完整买卖循环使用相同的基础币数量，因此配对买入金额精确等于卖出金额除以该格实际的 `卖价 / 买价`；实际格距会因价格精度略偏离配置的等比间距。理论上每格完整循环的卖出金额约为 `格预算 × (1 + 等比间距)`，实际值受价格和数量精度影响。初始卖格在现价买入的花费可能低于格预算，但其待卖数量已经全部买入。后续卖格平仓后在自身低边界以同一目标数量重新挂买单，买格成交后以实际成交数量挂高边界卖单。
- 手动追加 `Δ` 时每格预算增加约 `Δ/N`。有持仓的卖格按新旧预算对应的目标数量差额合并开多一次，再按持久化的逐格增量分配并调整卖单；已部分卖出的数量不会因追加资金被重新买回。空仓买格增加买入预算并调整买单。请求 ID 保证重复提交不重复加仓；若预览后卖格发生变化，请求会被拒绝，须重新预览。
- 价格越界时不移动上下界、不强平、不添加格子；已有对偶挂单继续工作。合约固定 1 倍做多，交易预算以外保留手续费和资金费余量。资金费不分配到每格预算。
- 预览按账户当前 maker/taker 费率计算每格挂单循环的预计净利润，以及初始合并开仓的预计 taker 费用。实际费用已经反映在币安账户余额中；本阶段的手动追加金额由用户明确输入。
- 详情页每格的交易次数按完整卖出循环累计；初始建仓价取启动时合并市价买单的实际成交均价，建仓均价和损益两平价取交易所当前 `LONG` 持仓，当前价取最近标记价，四项分开显示。纯网格毛收益按每格实际买卖成交价及 FIFO 配对数量计算，扣除已卖出数量对应的实际买入手续费和卖出手续费。启动或增资的合并买单为排除初始持仓趋势盈亏，以各格买线作为虚拟买入成本，并按分配数量分摊实际手续费；未卖出的部分暂不计入网格收益。币安 `realizedPnl` 按合约总仓位均价核算，包含趋势成分，因此只保留作核对数据，不作为纯网格盈利。资金费和浮盈亏不计入纯网格收益。收益率以当前网格总预算为分母，简单年化按策略首次启动至今的时长线性折算。成交记录或配对不完整、手续费以非 USDT 支付时，不展示收益率。短时间年化只用于观察当前节奏，不代表长期收益。
- 详情页超过 25 格时默认展示现价附近 25 格，可切换持仓格、空仓格、已成交格和全部。表格高度最多 520 像素，超出部分在表格内部滚动；筛选只改变展示，不改变订单或 Cell 状态。详情表在买入/卖出价后用括号显示对应的买入/卖出金额（U），不另设金额列；完成轮数、逐格复投次数和累计净利合并为“交易次数/复投次数/净利 (U)”一列，值用 `/` 分开。阶段文字不显示，仍用行颜色区分。逐格预算不在详情表重复显示。
- 币安 `SOXLUSDT` 属于 `TRADIFI_PERPETUAL`，不是 SOXLx 或 SOXLB 现货代币。测试网的 `PERCENT_PRICE` 限价带须从 `exchangeInfo` 动态读取：超过价格带的远端格子保留为逻辑格，价格靠近时才提交 post-only 限价单；若标记价在两次轮询间跳过格线，则按该格目标价提交 GTC 限价单，并记录事件。标记价和可成交价可能偏离，限价单保证买入不高于买线、卖出不低于卖线；若不能立即成交就挂在簿上等待。预览同时给出 maker 与双边 taker 的最低预计单格收益。

## 详情页规则速查

- “初始建仓价”是启动时合并市价买单的实际成交均价；“建仓均价”是交易所当前合约总持仓均价；“当前价”是最近标记价；“损益两平价”直接使用币安当前持仓字段，含已实现盈亏与手续费影响，不由纯网格收益反推。
- 启动时，程序一次性市价买入现价上方卖格的目标数量，并分配到各逻辑格。详情页仅显示当前持仓数量、已挂卖单数和因价格带暂未挂出的卖格数；价格靠近时才会提交远端卖单。
- 价格后括号内的金额使用同一格的配对数量分别乘以该格买价和卖价。已持仓格显示下一轮在该格买价重挂时的配对买入金额；首次建仓可能按不同的市价成交。每格交易次数按完整卖出一轮计 1 次；顶部“总交易次数”累计策略各格的完整轮次，包括已移除格子的历史轮次，不按成交碎片或下单次数计数。
- 纯网格盈利只累计已卖出数量对应的实际成交价差，并扣除其配对买卖手续费；初始合并建仓及增资买入以格线买价作虚拟成本，避免把启动时的趋势盈亏算成网格利润。成交价低于目标卖线的异常补单会如实计入网格亏损；总仓位的其他趋势盈亏、浮盈亏和资金费不在其中。收益率以当前网格交易预算为分母；简单年化按首次启动至今的时间线性折算，短时间数值不能代表长期收益。

## 逐格自动复投

- 固定网格可单独开启或关闭自动复投，默认关闭。仅在该格卖单完成一轮、且下一张买单尚未提交时检查；已有持仓和卖单不为复投单独买币。
- 只使用该格累计已实现净网格收益（扣除实际 USDT 手续费）。扣除已复投金额后，若剩余净利至少为该格买价乘以交易所数量步长，则把该格预算及策略总预算增加这一个步长对应的 U 金额。SOXL 的步长若为 0.01，便是让该格下一轮买卖数量增加 0.01 SOXL；每次完整卖出最多增加一个步长。
- 复投记录保存格子、轮次、增加数量、使用净利及当时利润快照。记录和预算更新在同一个数据库事务内提交；同一格同一轮不能重复复投。净利润不足、成交历史或手续费不完整、可用余额不足时跳过，不影响常规网格买单；剩余未使用利润留待下次完整卖出后检查。
- 每格“累计净利”沿用相同口径：一张卖单分批成交时，每笔卖出立即按其数量计算格线价差，按先买先配扣除相应买入手续费及该笔卖出手续费；未卖出数量的买入手续费留待后续配对。首次合并建仓及追加资金的买入手续费按分配数量摊到各格。仅在成交历史覆盖完整、买卖配对完整且手续费币种为 USDT 时显示数值，否则显示“—”；完整历史中所有格子（包括已移除格子）的未四舍五入净利之和等于顶部纯网格盈利。
- “追加资金”预览列出每格增加金额、卖格合并买入金额、买格新增预算和预计开仓手续费；确认后调度器按实际成交数量分配。停止策略只暂停调度，已有挂单和仓位仍需另行处理。

## 交易安全与恢复

- 本阶段代码阻止固定网格在币安生产域名启动。启动前检查价格位于区间内、交易预算不高于可用 USDT、该交易对没有既有持仓和挂单，并要求固定网格独占该交易对。
- 合并开仓前持久化操作 ID 和客户端订单号。发单结果未知时按客户端订单号查单，不盲目重发。确认完整成交后，预算与逻辑持仓在一个 SQLite 事务中应用。部分成交或数量不一致进入人工检查。
- 增资前同步原有挂单及成交，核对交易所实际仓位与逻辑仓位。增资后按最终成交结果撤换受影响的买卖单。进程重启后可根据持久化操作和订单号继续处理。
- SOXL 这类 TradFi 永续的资金费间隔和上限可能变化；本版不按格摊分资金费，运行前需查看交易所当时的费率并在预算外留余量。
- SOXL 测试网前两次 80 格、800 U 尝试被 `-4411`（需要签署 TradFi 永续协议）明确拒绝；账户持有人在币安 Demo 完成剩余确认并手动验证开平仓后，第三组 800 U 策略成功运行。按用户要求，该组已撤销 15 笔挂单、平掉 6.55 SOXL 并归档，交易所 SOXL 仓位和挂单核对为 0。随后按新的逐格数量算法新建 `soxlusdt-fixed-6fe1dc78`，区间 51.46–76.69、80 格、每格 50 U、总预算 4000 U、5 秒轮询。首次合并建仓 28.73 SOXL，均价 62.93；40 个初始卖格的卖出目标金额约为 49.56–50.23 U，交易所与逻辑仓位一致，策略状态为运行中。挂单数量会随行情变化。程序不会代签协议。
- 停止策略只暂停调度，不会自动撤单或平仓。需要停用时先在测试网核对挂单和仓位；验证脚本的 `--execute` 流程会清理自己创建的挂单与仓位。
- 测试网验证脚本默认只读；显式 `--execute` 才下单，并在结束时撤销本次挂单、平掉本次测试仓位。
